# Story Studio English–Bangla terminology

Use this glossary when editing either edition. Bold controls in instructions must match the current application exactly. Explanatory prose may vary naturally without changing meaning. Review this file and affected real screenshots whenever a displayed label changes.

## Recurring concepts

| English concept | Bangla explanatory prose | Exact UI wording, when applicable |
| --- | --- | --- |
| Story scaffold | গল্পের গাঁথুনি | A concept, not a control label |
| Story properties | গল্পের তথ্য | **Story Properties** → **গল্পের তথ্য** |
| Timeline | সময়রেখা | Envisioned; no current timeline control |
| Unresolved commitment | এখনও না-মেটা বিষয় | **Unresolved commitments · {count}** → **এখনও মেটেনি · {count}টি বিষয়** |
| Preview | প্রস্তাব / আগে দেখে নেওয়া | Use the full displayed action label in instructions, e.g. **Continue to preview** → **চালিয়ে যান** |
| Narrative intention | গল্পে কী করতে চান | The intention buttons below; not a separate control with this phrase |
| Author-approved | লেখকের অনুমোদিত | **AUTHOR-APPROVED CONCLUSION** → **আপনার অনুমোদিত সমাপ্তি** |
| Interface language | অ্যাপের ভাষা | **Interface language** → **অ্যাপের ভাষা** |
| Story language | গল্পের ভাষা | **Story language** → **গল্পের ভাষা** |

## Exact intention buttons

| English UI | Bangla UI | Meaning in prose |
| --- | --- | --- |
| Expand | বিস্তার করুন | গল্পে নতুন কিছু যোগ করা |
| Deepen | আরও গভীরে যান | চরিত্র বা পরিস্থিতিকে আরও গভীরভাবে দেখা |
| Escalate | জটিল করুন | জটিলতা, সংঘাত, বিপদ বা গুরুত্ব বাড়ানো |
| Reveal | জানতে দিন | আগে অজানা তথ্য প্রকাশ করা |
| Connect | যোগ করুন | গল্পের বিষয়গুলোর মধ্যে সম্পর্ক তৈরি করা |
| Redirect | মোড় ঘোরান | গল্পের দিক বদলানো |
| Resolve | মীমাংসা করুন | এখনও না-মেটা বিষয় মেটানো |
| Conclude | শেষ করুন | সমাপ্তির বিষয়ে লেখকের সিদ্ধান্ত নেওয়া |

**জটিল করুন** is the author-approved Escalate label. Other intention labels retain the established application wording. A proposed rename needs a clear semantic reason and author approval before changing the catalog or instructional labels.

## Availability and language

Keep **Available / এখন আছে**, **Prototype / পরীক্ষামূলক নমুনা**, and **Envisioned / পরিকল্পনায়** distinct. Available means verified in the private experimental build, not publicly released. Use এখনও প্রকাশ না-করা পরীক্ষামূলক অ্যাপ for private availability where helpful; do not confuse this with a feature’s prototype status.

Interface language and story language are separate. New stories currently default to English even in the Bangla interface. Authors can change story language independently; switching the interface does not translate or alter existing story text. Unicode text is accepted independently of both settings.
