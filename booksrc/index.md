# {{ page.title }}

**Edition:** English · [বাংলা](bn/index.html)

A story can begin with a promise, an image, or a question you cannot leave alone. Story Studio is an exploration of a workspace that helps you develop that beginning while keeping the story yours.

This public companion describes the **writer experience we want to deliver** and the parts we can already demonstrate. Studio itself is a **private, local, experimental application**. Publishing this book does not make the application public, downloadable, or supported. There is no public Studio release announced here.

You decide what matters, what becomes true, and what stays unresolved. The intended collaboration is straightforward: you imagine; Studio helps organize; an LLM may elaborate; you decide what to keep. A welcome surprise can enrich your story without taking it over.

## Read the status labels

| Label | Meaning in this book |
| --- | --- |
| **Available** | Verified in the current private application. It does not mean publicly available. |
| **Prototype** | Demonstrated experimentally; limitations and any separate tools must be stated. |
| **Envisioned** | A planned or conceptual interaction, not an existing control. |

An **outline** describes a future chapter, not a completed tutorial. Feature status and chapter completeness are different things.

The first three chapters form this initial book foundation. [The workspace](topics/workspace.md) orients you, and [the tiny-story exercise](topics/first-story.md) demonstrates a complete structural beginning-to-ending journey using real controls. The [larger-story working method](topics/richer-story.md) and [Maya mystery workshop](topics/impossible-letter.md) now extend that foundation. The other later chapters remain brief outlines.

The exercise and screenshots were verified on **8 November 2026** in the private build. Its interface currently says **Storybuilder · Narrative Workshop**; this book uses **Story Studio** for the broader vision. Screenshots are real application captures using a fictional sample, not interface mockups.

You do not need the private application to read this book. To perform an Available exercise, you need access to a private local build provided separately. This book does not provide that access.

**Available:** an English/Bangla interface and editable story properties. The book has corresponding English and Bangla editions, including real screenshots of the same tiny-story exercise. Story language and interface language are independent; your writing is not automatically translated.
